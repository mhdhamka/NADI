# Rakyat Electronics Sales Tracker

A C++ based sales tracking system developed for a Data Structures and Algorithms project.

## Features

- Create and manage customer orders
- Add, edit, delete and view product records
- Generate receipts
- View daily sales summary
- Sort sales records by:
  - Model Type
  - Subtotal Price

## Data Structures Used

- Singly Linked List

## Algorithms Used

- Searching Algorithm
- Sorting Algorithm

## Programming Language

C++
